# 中島テンプレ(物理・力学の記述答案)

新しい問題を受け取ったら、**現象理解 → 解法 → 図示 → 立式 → 計算 → 吟味** の順に進め、中島先生の型で答案を書く。
図は `figures.md` の約束と `tools/draw.mjs` の部品で描く。答案は HTML(数式は図形化)で出す。

## 0. 進め方(省略しない)
1. **現象理解**: 状態を数える(いつ・どこ・何が)。「静止」「限界」「動き出す」「離れる」などの言葉を拾う。
2. **解法**: 問題文の言葉を法則に落とす(下の「解法マップ」)。迷ったら `laws.md` を読む。
3. **図示**: 法則に合う図を、白紙から描く(`figures.md`)。問題の図の写しではなく、生徒が白紙から書ける図にする。
4. **立式**: 法則名の見出し → 式。
5. **計算**: 操作を一言で添えて進める。
6. **吟味**: 解の取捨、物理的にありえるか(下の「吟味」)。

## 1. 解法マップ(必然性)
```
運動方程式 ma=F  ─ 変数 F, a, x, v, t
  ├ v = v0 + at     → 力積と運動量の関係 → (2物体なら)運動量保存則
  ├ x = v0 t + ½at² →(時間・位置を求めるとき)
  └ v² − v0² = 2ax  → 仕事とエネルギーの関係 → (保存力のみなら)エネルギー保存則
                      ※ v-t グラフ: 傾き=加速度、面積=変位
二体問題(衝突・分離・台と物体)は3本の式:
  ① 運動量保存則  ② エネルギー保存(または仕事とエネルギー)  ③ 相対速度 → 衝突ははねかえりの式  −e = (v' − V')/(v − V)
円運動(等速・非等速): 向心方向の運動方程式 m v²/r = ...  +  (非等速なら)エネルギー保存則
                      ※ 等速円運動の公式: vT=2πr, ωT=2π, a = rω² = v²/r
剛体: 力のつりあい + 点◯のまわりのモーメントのつりあい(回転軸を ▲ で示す)
```
問題文のキーワードと法則の対応(例):

| 問題文のことば | 落とす先 |
|---|---|
| 静止している・つりあう | 力のつりあい(剛体は + モーメントのつりあい) |
| 動き出す・離れる・限界 | 限界の条件(`f=μN`, `N=0`, `T=0`, `v=0`)を置く |
| 2点の速さの関係(力の仕事を問わない) | エネルギー保存則 / 仕事とエネルギーの関係 |
| 時間・力積 | 力積と運動量の関係 |
| 衝突・分離 | 運動量保存 + はねかえりの式(+ エネルギー) |
| 加速する観測者(電車の中など) | 観測者を明記。慣性力 ma を加えるか、外から見た運動方程式 |
| 重心 | 重心の式、「重心に全運動量が集まっている」 |
| 二次方程式・比 | 解の取捨(吟味) |

## 2. 答案の構成(小問ごとに6項目)
小問ごとに、次の6項目に分けて書く(`tools/answer.mjs` の `qa()`)。項目名は左に出し、**項目ごとに色が違う**(現象=空色、解法=紫、立式=青、計算=黄、答=緑、吟味=朱)。

| 項目 | 書くこと |
|---|---|
| 現象 | 状況を言葉で整理する(状態・向き・条件)。**状況を表す図はここに置く** |
| 解法 | **問題文のどこを見て判断したか**を引用し(`[[…]]` で黄色のマーカー)、「→」で使う法則につなぐ |
| 立式 | 法則名の見出し + 式。**力の図・式に使う図はここに置く**。新しい記号はここで定義 |
| 計算 | 途中の式変形。**生徒が計算でつまずくことがあるので載せる**。ただし答案には書かないので、枠の中の「答案には書かない」小枠に置く(見た目で区別)。数値計算など書くべきものだけ `keisanKeep: true` で小枠なしにする |
| 答 | 結論(`∴ … .`)。選択式は番号も(`∴ ③ .`) |
| 吟味 | 最後の確認(符号・範囲・極限・次元・既知の式との一致)。補足の `※` は枠で別記 |

- **「答案に書く」範囲 = 立式・答**(必要な計算だけ加える)。薄い枠で囲み、「答案に書く」の札を付ける。現象・解法・吟味・途中の計算は考えるための項目で、答案には書かない。
- 途中式を出さない答案だけの版が必要なときは `node answers/<名前>.mjs none`(`<名前>.none.html`)。
- **式の説明は式の下に書く**: TeX の `\underbrace{…}_{\displaystyle\text{説明}}` を使う(例: `\underbrace{m v_1 - m v_0}_{\displaystyle\text{運動量の変化}} = \underbrace{-\mu' m g\,t_1}_{\displaystyle\text{力積(左向き)}}`)。説明は短く。
- **不要な改行はしない**: 結論の選択肢は式と同じ行(`eq(…, {ther:true, ch:'③'})`)、操作の一言も式と同じ行(`eq(…, {lead:'①+② より … して'})`)に置く。
- 解法の引用は、問題文の言葉をそのまま短く抜き出す(言い換えない)。
- 縦A4・1列で出す(2ページ以上になってもよい)。小問は途中で改ページしない。
- 項目の中身がないときは `—` と書き、項目名は省かない。

## 3. 答案の型
- 左端に小問記号。(1)(2)… または (イ)(ロ)…。複数設問をまたぐときは見出しの下に「(2)の結果より」と書く。
- **法則名を見出しにして、式を並べる**。見出しは太字だけにして、**下線・枠などの装飾はしない**(線を引く理由が無いため)。対象を明記する:
  `Aの上の物体に対する力のつりあい` / `点Oのまわりのモーメントのつりあい` / `Bから見た運動方程式` / `仕事とエネルギーの関係(小物体)` / `運動量保存則(x方向のみ成立)`
- **記号の定義は、問題文に書かれていない文字を新しく使うときだけ**、見出しの後ろの括弧に書く: `運動方程式(N:垂直抗力、T:張力)`。問題文で `N` や `μ'` が与えられているなら、定義は書かない。
- 式番号は丸数字 ①②③。操作は一言で: `①+②より v を消去して` / `②×cosθ−①×sinθ より R を消去して` / `②÷①より` / `②に①を代入して` / `2式より`。
  連立は括弧 { でまとめる。
- 結論は `∴` を付け、末尾に `.`(手書きの `//` に相当)。単位は [ ] で囲む。
- 正の向きの宣言を必ず入れる(「右向きを正とする」など)。
- **補足事項は別記する**: 本論の流れを止めない内容(別解、公式の導出、注意)は `※` を付けて枠外に書く。例: `※ v²−v0²=2ax より 0²−V²=2(−μg)L でも可.`
- 注釈は短く: `F大⇒T小`、`不変`、`|a| は大きさ`、`時間に注意`、`〜に相当`。
- 図の記号と式は ①②③・★ などで対応づける。状態(点・時刻)は図で ①②③ と番号を振り、式の項に同じ印を付ける。
- 別解は「別解」と明記して並べて書く。
- 文章量は最小限。入試の記述答案では、**設定した文字・採用した法則・仮定(例: 糸はたるまない)**を一文で添える。

- 選択式の問題は、導出のあとに `∴ ③ .` のように解答群の番号を書く(見本: `answers/2026-p3-1.mjs`)。
- 文中の点 O などの記号は数式(`$\\mathrm{O}$`)で書く(日本語フォントの O は 0 と見分けにくい)。
- 文字の大きさは統一する(本文・式・補足・図の中の記号で、大きさをばらつかせない。強調は大きさではなく太字・色で)。

## 4. 吟味(最後に必ず)
- 二次方程式は解が2つ → 条件で取捨(`d>0 より`)。
- 反発係数 0≦e≦1、時間・長さ・質量が正、`N>0`(離れない条件)、`T>0`。
- 場合分け・限界: 「傾く前にすべるので F3<F2」のように大小関係を書く。
- 極限・次元・θ=0 などの特別な場合で既知の式と一致するか(例: `θ=0 のとき ニの式と一致`)。
- 赤字で一言添える(HTML では `.check` クラス)。

## 5. 出力
答案は HTML 1枚 + PDF(**A4縦・1列**)。1ページに収める必要はない(余白が少なくなる縦を既定にする。2段組は `layout: 'two'` で選べる).数式は MathJax で図形化して埋め込む(フォントに依存しない)。

作り方(見本: `answers/2026-sample-4.mjs`):
1. `answers/<名前>.mjs` を作り、`tools/answer.mjs` の部品で本文を組む。
   `qa('(1)', { genshou:[fig(svg), p('…')], kaihou:p('…'), tate:[head('運動方程式','$T$:張力'), eq('ma = F')], keisan:[op('①+② より $t_1$ を消去して'), eq('…')], ans:eq('a = …\\ .',{ther:true}), gimmi:p('…'), note:note('…') })`
   - `head` 法則名の見出し / `eq` 式(`no:'①'` で式番号、`ther:true` で ∴)/ `op` 操作の一言 / `p` 文章
   - `note` 補足(※、別記) / `check` 吟味 / 文中の数式は `$...$`
2. 図は `tools/figures.mjs` の関数(`figA` 前後の図、`figB` 力の図示、`figC` 斜め衝突、`figD` v-t グラフ)か、問題用に `tools/draw.mjs` の部品で新しく描く。作用点は `figures.md` の表に従う。
3. `node answers/<名前>.mjs` で HTML(途中式つき)を作り、chromium で PDF にする:
   `headless_shell --no-sandbox --print-to-pdf=<出力>.pdf --no-pdf-header-footer file://…`
   図とPDFは必ず目で見て、文字の重なり・矢印の根元・数式の崩れを直す。
4. PDF のページ数と、ページ末の空白・図の重なりを目で確認する。
5. 原本(先生の答案)があれば並べて比べ、式の粒度・見出し・操作の一言を合わせる。

## 6. 不確かなときは
推測で埋めずに、先生に聞く。特に:
作用点が曖昧な力、正の向きが決められない設問、色の対応が `figures.md` に無いケース。
