# 法則別ひな形(迷ったとき用)

式は答案の型(SKILL.md §2)で書く。{ } は問題から埋める。

## 運動方程式
```
運動方程式(N:垂直抗力、T:張力)       ← 対象(物体名)と記号を明記
  ma = {力の和}        ← 正の向きを先に決める
  ∴ a = {…}.
```
- 力は対象の物体が**受ける**ものだけ。作用点を図で確認。
- 二物体: `A: m_A a = …` `B: m_B a = …` を並べ、`T を消去して`。連結は加速度の関係を式に(`a_A = a_B` など)。
- 加速する観測者: `Aから見た運動方程式` か `Bから見た(慣性力 −ma を加える)`。観測者を図に書く。

## 力のつりあい
```
鉛直方向の力のつりあい
  0 = N − mg   ∴ N = mg.
```
- 水平・鉛直(または斜面に沿う・垂直)の2方向。2方向とも書く。

## モーメントのつりあい(剛体)
```
点Gのまわりのモーメントのつりあい     ← 軸の点を明記(通る力の腕は 0)
  (時計まわり) = (反時計まわり)       ← 先に回転の向きを図に書く
  ∴ F = …
```
- 軸は、未知の力が通る点を選ぶと式が簡単になる。
- 限界(傾く・すべる)は2つの図を並べて、`限界: N の作用点が端`、`f=μN`。

## 運動量保存則 / 力積と運動量の関係
```
運動量保存則(右向きを正)
  m v0 = m v_A + M v_B      ← 前 = 後。x方向のみ成立するなら明記
はねかえりの式(衝突)
  −e = (v_A' − v_B') / (v_A − v_B)
```
- 「①と②より v を消去して」。力積: `I = Ft` や `m v' − m v = I`。
- 内力のみなら運動量保存。外力が働く方向は保存しない(x方向のみ成立)。

## 仕事とエネルギー / エネルギー保存則
```
仕事とエネルギーの関係(小物体)
  (1/2)mv'² − (1/2)mv² = −μmg·d       ← (後)−(前) = 非保存力の仕事
エネルギー保存則
  (1/2)mv0² + mg·h = (1/2)mv² + mg·0   ← 保存力のみのとき
```
- 始点と終点を図で①②と決めてから式を書く。
- 非保存力(摩擦)があるときは「仕事とエネルギーの関係」。

## 円運動

```
向心方向の運動方程式
  m v²/r = {向心方向の力の和}
エネルギー保存則
  …
```
- 離れる条件 N=0、糸がたるまない条件 T≧0(最高点で T=0 が限界)。
- 向心加速度 ⇨ を図に描く。

## 放物運動・斜面
```
x方向は等速なので  x = v t
y方向について  y = v0 t + (1/2) a t²
```
- 斜面では x 軸を斜面に沿ってとり、重力を gsinθ・gcosθ に分ける。
- 繰り返す衝突: 等比数列の和(`|r|<1` を確認、`e^n ≒ 0` と吟味)。

## 重心
```
重心の式(x方向)  x_G = (m x_1 + M x_2)/(m+M)
重心に全運動量が集まっている → v_G = (m v + M V)/(m+M)
```
- 外力が無ければ重心は等速(静止なら静止)。

## 単振動・万有引力(2021資料より)
```
力のつりあい(つりあいの位置 = 振動中心)  0 = k x0 − mg
振動中心を図に描き、振幅 A = (端 − 振動中心) を寸法線で示す
参照円に着目して、 v = rω より …            ← 単振動 = 円運動の射影
ωT = 2π より  T = 2π/ω
運動方程式  m a = −(定数)x  ∴ a = −ω²x、 ω = √(定数/m)
エネルギー保存則(振動中心を基準)  (1/2)mv² + (1/2)k x² = (1/2)k A²
```
- 万有引力: `F = G Mm / r²`、地表では `mg = G Mm/R²` ∴ `GM = gR²`。
  地球内部(トンネル): 半径 |x| の球の質量は体積比 → `M' = M |x|³/R³`、力は `(mg/R)|x|` で原点向き。
- 運動方程式の形に直して「−ω²x の形だから単振動」と結論する。
- 図: 振動中心(●)、振幅の寸法線(青)、参照円に ω、θ、v = rω を書く。

## 相互運動・二体問題(3点セット)
`① 運動量保存則 → 内力の和は 0(外力が無い方向のみ)`、
`② エネルギー保存則(2物体の全体)`、`③ 相対速度 → はねかえりの式`。
状態に ①②③④ を振り、式の項に同じ番号の囲みを付けて対応づける(`①`: 前、`④`: 後 など)。
