# 図のルール(中島テンプレ)

作図は `tools/draw.mjs` の部品を使う。色は `C` で一括管理。見本は `figures/` と `tools/build-figures.mjs`。

## 1. 基本方針
- 図は**白紙から**描く。問題の図を写し取っただけの図にしない(生徒が黒板・ノートで再現できる単純さ)。
- 物体は □ / ○ に省略。余計な描写はしない。必要なものだけ: 物体、面、軸、状態、力、速度、距離。
- 法則に合わせて図の種類を選ぶ(下の「法則別の図」)。
- 図の中に正の向き・軸(x, y)・原点 O を入れる。

- **力の図には、物体が受けるすべての力を載せる**(重力・垂直抗力・摩擦力など)。摩擦力は接触面から、すべる向きと反対(静止なら動こうとする向きと反対)に描く。
- **図の中の日本語も数式と同じ大きさ**(`JS` = `FS` = 22。表示すると本文と同じ大きさ).
- **図は枠(□)で囲まない**。白地に直接描く。
- **加速度の矢印は、正の向きにそろえる**(上向きが正なら a も上向き)。式は正の向きを基準に立て、結果の符号で実際の向きを判断する。力の矢印は実際の向きに描く。
- **力の矢印と、その力の記号は同じ色**にする(例: 矢印がオレンジなら N・mg・μN もオレンジ)。分解成分や求める量も、矢印と記号を同じ色にする。
- **その設問で使う情報だけを描く**。力のつりあいの図に速さ v₀ は描かない(つりあいに速さは関係ない)。運動量・エネルギーの図には速さを描く。
- **2物体あるときは、物体を離して描く**。力の図は対象の物体1つずつ描き、重ねない・積まない(接触面は短い線で示す)。
- **文字の大きさをそろえる**: 図の中の記号は全図で同じ大きさ(`FS`)、日本語は同じ大きさ(`JS`)。図の表示幅は viewBox の幅 × `--k`(= 本文の文字 ÷ FS)に固定し、図の記号が本文と同じ大きさに見えるようにする(`tools/answer.mjs` の `fig()`)。図の余白は切り詰める。

## 2. 作用点(最重要)
どこから力を受けているかを、矢印の根元(作用点)で表す。

| 力 | 作用点 |
|---|---|
| 重力 mg | **重心**(物体の中心) |
| 垂直抗力 N | **面と接している部分**(接触面上) |
| 摩擦力 f(μN) | **面と接している部分**(接触面上。N と同じ点) |
| 張力 T | 糸と物体の接点 |
| 手・押す力 | 手がふれている点 |
| 浮力・万有引力 | 重心(物体の中心) |
| 圧力・面から受ける合力 | 接触面の中心 |

- 作用点には点(●)を打つ(`dot`)。
- **重力と垂直抗力は一直線上に重ねない**。重力は重心から、垂直抗力は接触面上で横にずらして描く(同じ線上だと作用点が分からなくなる)。
- 剛体では作用点の位置がモーメントを変える。**ここを崩さない**。
- 手書きの原本は重心から全部出していることがある。**原本をそのまま真似ず、上の表を優先する**。曖昧なら聞く。

## 3. 色(Okabe-Ito 系。赤は見えにくい人がいるので朱を使う)
| 意味 | 色 | 備考 |
|---|---|---|
| 力(1次元) | オレンジ | 矢印を太め(`force`) |
| 加速度 | オレンジの白ぬき二重矢印 ⇨(`accel`) | 重力加速度 g も ⇨ |
| 力・速度の**分解**成分 | 注目方向=朱(compA)、それに垂直=青(compB) | **注目方向 = 運動方程式やつりあいを立てる方向**。斜面なら斜面沿いが朱・斜面に垂直が青。円運動なら向心方向が朱・接線方向が青。水平/鉛直に分けるときは、運動方程式を立てる方向を朱にする |
| 速さ・速度 v | 黒 | 細め |
| 距離・長さ | 黒(寸法線) | 求める長さは緑 |
| 求める量・面積 | 緑 | |
| 状態ラベル(t=0 など) | 青 | |
| 慣性力(見かけの力) | 朱 | `ma` と書く。観測者を明記 |
| 床・壁 | 灰、斜線 | 斜線は物体の反対側 |
| 上記以外の物理量 | 色を付けない | 問題で説明が必要なときだけ付ける |

## 4. 記号・矢印
- 矢印の根元が作用点、先が向き。力・速度・加速度の長さは大小に比例させる(つりあう力は同じ長さ)。
- 速度は物体の横に `→ v`、静止は `止` と書く。
- 位置・距離は寸法線(`dim`): 左端に縦棒、右へ矢印、中ほどに記号。
- 状態を並べる図は「前/後」「t=0 と t=t₁」を同じ座標に上下に並べる。位置は同じ基準線から測る。
- ばねは「自然長 `自`」「縮 x `縮`」を丸で囲んだ印で示す。
- 観測者は人の形(♀)で示し、「Aから見た」「床上の人」を図にも書く。
- 内力は丸で囲む(`T` を○)。
- 回転軸は ▲(黒三角)、モーメントの腕は点線の補助線と直角記号。

## 5. 法則別の図
| 使う法則 | 描く図 |
|---|---|
| 力のつりあい・運動方程式 | 対象の物体を1つ描き、重心・接触面から力を出す。対象を決める(「Aの上の物体」など) |
| 運動量保存・衝突 | 前/後を上下に並べ、各物体に速度矢印と速さの記号。正の向きを書く |
| 衝突(斜め) | 面と角度、成分に分解、力積 |I| は面に垂直 |
| エネルギー保存・仕事とエネルギー | 始点と終点の2状態(①②)、高さ h・移動距離 x、力を距離に沿って描く |
| 円運動 | 向心方向の加速度 v²/r(⇨)、力は向心・接線に分解(元の力は細い破線、成分は実線) |
| 剛体のつりあい | 回転軸 ▲、力の作用線、腕の長さ、重心 |
| 限界の2状態(すべる限界/傾く限界) | 2つの図を並べて描く |
| 単振動(時間・周期) | **参照円と x-t グラフ**を並べて描く。**円のどこからどこまで動くか(例: A から B の半周、ωt: 0 → π)を緑の弧と矢印で示し、グラフの対応する区間(t = 0 → T/2)も同じ緑で示す**。A・B の高さを点線で円とグラフにつなぎ、±R と T/2 を書く。速さの分解は、この図には描かない |
| 単振動(エネルギー保存) | 状態①(端で静止)から状態②(中心から r、速さ v)への移動を示す図を描く。①②の位置、中心からの距離 R・r、移動の向き(緑の点線の矢印)を入れる |
| v-t グラフ | 軸 v, t、傾き=加速度、面積=変位は斜線(緑) |
| 二体の位置関係 | 物体ごとの移動距離 x, X と相対距離 s を色分けの寸法線で(s = x − X) |

## 6. 図の作り方
`tools/build-figures.mjs` に1図ずつ関数を書き、`npm run figures` で `figures/*.svg` を作る。
文字は `tex(x, y, 'v_0', {size, color, anchor})`(MathJax で図形化)。日本語は `jp()`。

## 7. 状態番号と対応づけ(2021資料より)
- 図の中の状態(時刻・位置)を ①②③④ の丸数字で示し、式の中の項(運動量・エネルギーの項)にも同じ番号の丸や枠を付ける。
- 回転の向きは ⟲ ⟳ を丸で囲み、時計まわりと反時計まわりで色を変える(朱/青)。
- 気体・電磁気は未収録(力学を先に完成させる)。

## 8. 斜面・ばねの図(R-7, R-8 の経験)
- 斜面: 斜面の下は薄い灰色の面(斜線は引かない)。物体は斜面に沿った長方形。力の図は、重力 mg を細い破線(重心から)、斜面に沿う成分を朱、垂直な成分を青、N と摩擦力は接触面から(N は斜面の上側にずらす)。名前(A, B)は物体の斜面上側の脇に置く。
- 衝突の前後・エネルギーの前後は、同じ斜面を2つ並べる(「衝突直前/直後」「初め/最後」)。速さの矢印は動く物体の上側に描き、名前や「止」と重ねない。
- ばね(鉛直): 左に x 軸(下向きが正)と 0・x₀・x₃ などの高さの点線を引き、状態ごとに列(ばね + 板 + 小球)を並べて ①②③④ を振る。
- 2物体の力の図(板 A と小球 C)は、離して描き、加速度 a は正の向きにそろえる。

## 9. 円運動・遠心力・つり下げ(問題集 2026 の経験)
- 小球とともに運動する観測者から見る問題では、**遠心力(慣性力)は朱**で、矢印と記号(m v²/r など)を同じ色にする。重力・張力・垂直抗力はオレンジ。
- 力の長さは大きさに比例させる(例: N₁ = 3mg なら mg の 3 倍の長さ、遠心力 2mg なら 2 倍)。
- 力の図の文字は、本文と同じ大きさに縮小されるので、**図の寸法は大きめ(幅 400〜500 px、物体の間隔 140 px 以上)**に描く。小さく描くと文字が重なる。
- 力が多い図は、力を左右にずらして描き(重力を左、垂直抗力を右など)、ラベルは矢印の先の外側に置く。
- 斜面+滑車: 斜面は問題の図と同じ向き(右上がりなど)で描く。成分を描くと混み合うので、図を大きくする。
