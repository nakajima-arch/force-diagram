# 力の図示の決まり(数研の教材から学んだこと)

力の図は `tools/forces.mjs` の部品で描く。見本は `figures/force-diagrams.html`(`npm run forcedemo`)。

## 1. 作用点(どこから出すか)
- 作用点には必ず **● を打つ**(`force()` は根元に ● を自動で打つ)。
- **重力**: 物体の**重心**(物体の中心)から鉛直下向き。物体の内側に ● がある。
- **重力以外はすべて、物体が直接ふれているところから受ける力**。作用点は**接触点**。
  - 垂直抗力 N: 面との接触点から、面の外向き。
  - 摩擦力 f: 面との接触点から、面に沿って、**動こうとする(動く)向きと逆**。
  - 張力 T: 糸との接点から、**糸に沿って糸の側へ**。
  - 弾性力: ばねとの接点から、ばねの側へ(伸びていればばねの側、縮んでいれば逆)。
  - 手が押す・引く力: 手がふれている点から。
- **ふれていないものの力は描かない**: 「物体が手から受ける力」(手がはなれた後)、「動く向きにはたらく力」(慣性)は存在しない。
- 小球(質点として描く物体)は、力を球の中心付近から描く(教材では、球の中に ● を打って、そこから出す)。
- 重力と垂直抗力など、同じ線上に重なるときは、作用点をずらして描く(物体の中央と接触点が自然にずれる).

## 2. 長さ(どれくらいの長さか)
- **矢印の長さは力の大きさに比例**させる(`fvec(P, 向き, len)` の len = 大きさ × 1 単位の px).
- **つりあう力は同じ長さ**にし、**「=」の印(短い横線)を同じ数だけ**付ける(`ticks`). 例: N = mg、f = F、T₂ = mg.
- つりあっていないときは、長さを変える。例: 上向きに加速する物体は、手の力 f > 重力 mg。下向きに加速する B は、mg > T.
- 軽い糸の張力は、どこでも同じ長さ(同じ印)。

## 3. 向き(どの向きか)
- 力の向きは、**物体が相手から受ける向き**で決める(物体から見て相手の側 / 相手から離れる側を間違えない).
- 運動の向きは**細い黒矢印**(力ではない)。力は色つき(オレンジ)。加速度は **⇨(白ぬきの太い矢印)** で、力とは別に、横に描く(`acc()`).
- 連結した物体は、**物体ごと**に点線の枠(`focusBox`)で囲み、**加速度 ⇨ も物体ごと**に描く。作用・反作用は別々の物体の図に描く.
- 軸 x, y と**正の向き**を図に描く(上向きが正など)。

## 4. 斜面
- 重力を**点線の長方形**で、斜面に沿う成分(朱)と垂直な成分(青)に分ける(`resolveGravity`)。長さは mg sinθ、mg cosθ に比例。
- **斜面に沿う力(摩擦力・張力)は朱、垂直な力(垂直抗力)は青**。つりあうとき、成分と同じ長さの力に同じ「=」の印。
- 30°・60°・90° の直角三角形は、辺の比 **1 : 2 : √3** の三角形を添える(`ratioTriangle`)。
- 摩擦力の向き: 静止なら動こうとする向き(斜面を下ろうとする)と逆 = 斜面を上る向き。すべり下りるなら、運動と逆 = 斜面を上る向き。

## 5. 手順(教材の「基本プロセス」)
1. 注目する物体を決める(点線で囲む)。
2. その物体に**作用点(●)**をかく。
3. **向きに注意して矢印**をかく。長さは大きさに比例(つりあいは同じ長さ + 印).
4. 軸と正の向きを設定する。
5. 力を軸方向に分解して、運動方程式 / つりあいの式を立てる。
